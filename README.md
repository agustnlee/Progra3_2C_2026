# Programación III – UADE

Repositorio de la materia **Programación III Viernes TT (Grupo AJS)**, correspondiente al segundo cuatrimestre de 2026 de Ingeniería Informática en UADE.

El repositorio se utiliza tanto para el desarrollo del **Trabajo Práctico Obligatorio (TPO)** como para almacenar las tareas y ejercicios realizados durante la cursada.

## Estructura del repositorio

- `tpo/`: código fuente, pruebas y documentación del TPO, correspondiente a nuestra solución para la propuesta de una red social universitaria.
- `informes_tpo/`: Archivos pdf para los informes de las entregas 01 y 02.
- `tareas/`: Algunas tareas, ejercicios y demás actividades prácticas de la materia.
